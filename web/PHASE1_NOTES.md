# Фаза 1 — рабочие заметки (веб-порт)

Статус на 2026-10-12. Правки НЕ закоммичены (ждут отмашки).

## PoC (Фаза 0) — пройден

- Рейкастер крутится в WASM: ~15 FPS в Firefox, ~19 FPS в headless Chrome
  (нативный ориентир render-only ~34 FPS). Вердикт — GO.
- **Ключевой фикс:** во входном файле `import numpy` идёт ДО `import pygame`.
  pygbag грузит .so-wheel'ы в порядке обнаружения импортов; в emscripten SDL
  слинкован в несколько .so, и если numpy грузится после pygame — он затирает
  регистрацию SDL-дисплея (`set_mode` падал: "The video driver did not add any
  displays", num_displays=0). numpy раньше pygame → дисплей сохраняется.

## Сделано в Фазе 1 (проверено headless)

- **Async-цикл.** `src/app.py`: тело цикла вынесено в `_tick(dt)`, добавлен
  `async run_async()` (yield браузеру каждый кадр). Десктопный `run()` по
  поведению не изменился. Десктоп по-прежнему через `run.py`.
- **Продакшн-вход** `web/web_main.py` (numpy→pygame, App + SplashScene +
  run_async). Проверено: splash → меню → NEW GAME → геймплей рендерятся без
  ошибок, set_mode OK (960×600).
- **Сохранения под браузер.** `src/save.py`: в вебе сейв в `localStorage`
  (ключ `chronokhryshch_save`), на десктопе — файл `save.json`. Проверено:
  NEW GAME пишет сейв, он переживает перезапуск браузера, после перезагрузки
  CONTINUE становится активным. Сейв крошечный → localStorage, без IDBFS.
- **index.html / Quirks.** `web/chrono.tmpl` — своя обёртка (копия pygbag
  default.tmpl + `<!DOCTYPE html>` + `html/body{overflow:hidden}` + тёмный фон
  + тёмный лоадер). Чинит Quirks mode и большие полосы прокрутки. Передаётся
  через `--template chrono.tmpl` (build_poc.sh копирует и подставляет флаг).
  Проверено: compatMode=CSS1Compat, переполнения нет.
- **Сборка.** `web/build_poc.sh` параметризован: 1-й арг — входной файл
  (по умолчанию `web/main.py` = PoC-харнес). Прод-сборка:
  `bash web/build_poc.sh web/web_main.py`. Добавлен `PYTHONUTF8=1` (иначе pygbag
  на Windows читает входной main.py в cp1251 и падает на кириллице).

## НУЖНА ПРОВЕРКА В РЕАЛЬНОМ БРАУЗЕРЕ (Firefox)

Headless маскирует жест autoplay-флагом, поэтому эти пункты я не смог
подтвердить сам. Сервер поднят: открой **http://localhost:8000** в Firefox.

1. **Звук.** После клика «старт» (pygbag сам показывает запрос на жест через
   `ume_block`) — играет ли музыка и SFX? Переключатели MUSIC/SOUND FX в меню
   работают? (Если звука нет — отдельная задача про аудио-жест.)
2. **Обзор мышью (pointer lock).** В геймплее мышь должна вращать камеру
   (`pg.event.set_grab(True)` → запрос pointer lock, браузер может показать
   подсказку). Проверь: обзор работает, Esc/потеря фокуса не ломают игру.
3. **Полный дымовой тест** (п.8 плана): меню → старт → обзор мышью → звук →
   WASD и столкновения → взаимодействие E → заморозка времени F → ловушки/урон
   → пауза и Esc → сохранение/язык/настройки звука переживают перезагрузку →
   завершение уровня → переход между уровнями → финал.

## Как тестировать (headless, без меня)

Серверы pygbag: `bash web/build_poc.sh web/web_main.py` (прод) поднимает
http://localhost:8000. Инструменты в scratchpad/hrunner (puppeteer + Chrome):
`node run.js <url> <ms>` (ловит POC_*), `node shot.js <url> <out> <ms>`
(скриншот), `node drive.js` (меню→NEW GAME→геймплей), `node verify_persist.js`
(сейв через перезапуск). Ключевой флаг Chrome для headless:
`--autoplay-policy=no-user-gesture-required` (обходит pygbag ume_block).
